# Security

Squads is a static site: HTML, a JSON data file and images, with no server code, accounts or stored personal data. Game stats live only in the player's browser.

## Reporting a problem

Please report security issues privately through [GitHub's vulnerability reporting](https://github.com/RexDotDev/postava/security/advisories/new), not as a public issue. Include what you found, where, and how to reproduce it.

Relevant reports include script injection through the lineup data or the page, and problems in the build scripts or the GitHub workflow. Wrong lineups are not security issues; use the "Wrong lineup" issue form.
